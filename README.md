## 关于我

目前主要探索大模型应用、智能体工作流和数字人交互，也在学习 Python 后端开发与软件测试。做项目时，我关心功能能否真正用起来，也关心文档、部署和后续维护。

我加入 [Pieces Lab](https://github.com/Pieces-lab)，希望分享自己的作品与开发过程，向社区里的创作者学习，并和大家交流 AI 与软件项目的实际落地。

对我来说，动手做出一个可用版本，再从真实问题中不断改进，是持续学习的动力。这个仓库会记录已经完成的作品，也会保留仍在探索的方向。

### 数字心屿 · AI 情绪陪伴数字人

围绕数字人“小安”开发的开源 Web 应用，结合文字与语音对话、心理学知识检索和用户可控的长期记忆。项目聚焦日常陪伴与非诊断性的情绪倾听。

[项目介绍](projects/digital-human-companion.md) · [源码与使用说明](https://github.com/linyuchao123/digital-human-companion)

### AI 英语口语陪练

面向英语学习者的场景化练习平台，围绕面试、点餐和会议对话提供发音反馈、语法纠错与课后报告。
